In the IBM Concert Labs of the AIOps Jam-in-a-Box series, you will be
going through several key exercises in order to learn more about the features 
and capabilities of IBM Concert.

Lab list:

- [**Application Vulnerability Management**](../app-vul-mgmt/1-introduction/index.mdx)
  - In this Lab, we explore how Concert can auto discover vulnerabilities from source code repositories and kubernetes clusters.


- [**WebSphere Vulnerability Remediation**](../websphere-vuln/1-introduction/index.mdx)
  - In this Lab, we explore how Concert can auto remediate WebSphere ND and Liberty vulnerabilities.
