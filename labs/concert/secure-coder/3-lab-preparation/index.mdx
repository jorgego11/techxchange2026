# 3. Lab Preparation

## 3.1: Overview

Before installing and using the Concert Secure Coder extension, complete **all Lab Preparation steps** in this section. These steps get you onto the Bastion Host, connected to IBM Concert, and set up with a credentials file you will fill in as you go.

:::warning
You may receive prompts for software updates during the lab (for example, from the browser or Visual Studio Code).
Please **ignore these prompts** and **do not install any updates**, to avoid disrupting the lab environment.
:::

If you encounter a browser security warning such as **"Warning: Potential Security Risk Ahead"** when reaching Concert, this is expected — the lab uses an internal, self-signed certificate. Select **Advanced** then **Accept the Risk and Continue**.

---

## 3.2: Using the Bastion Host

This section provides background about the Bastion environment. You will run installation steps and scans in later sections.

### 3.2.1: Accessing the UI

From the **Bastion Host**, click **Activities** and open **Firefox**. The Concert bookmark is pre-configured:

- **Concert UI**: `https://concert.ibmdte.local:12443`

### 3.2.2: Using SSH from the Bastion Host

If a later step needs command-line access, you can connect from the Bastion to the Concert host over SSH:

```bash title="Host: bastion-gym-lan"
# Access the Concert VM
ssh jammer@concert
```

:::tip
SSH from the Bastion uses key-based authentication — no password is required when connecting to lab VMs.
:::

## 3.3: Creating the Credentials File

You will collect a few values as you work through the lab. Keep them in a single text file so they are easy to reference in later sections.

### 3.3.1: Prepare the Credentials File

1. From the **Bastion Remote Desktop**, on the left panel click **Show Applications** then **Text Editor**.
2. Create a new file named `credentials.txt`.
3. Paste the template below and **save** it.
4. Keep this window open for easy access during the lab.

```text
# Concert Secure Coder Lab Credentials
# ====================================

Concert URL:      https://concert.ibmdte.local:12443
concert_username: ibmconcert
concert_password: Passw0rd

# Filled in during Section 4 (Install and Configure)
Secure Coder URL:
Concert API Key:
```

:::important
Keep this credentials file open throughout the lab. You will fill in the **Secure Coder URL** and **Concert API Key** in Section 4, when you open the Get Started panel. The API key is shown only once and is non-recoverable, so copy it into this file immediately when it appears.
:::

## 3.4: Access the IBM Concert UI

Verify that you can reach and sign in to IBM Concert. This is where you will download the Secure Coder extension in the next section.

### 3.4.1: Steps to Access Concert

1. From the **Bastion Remote Desktop**, open **Firefox**.
2. Click the **Concert** bookmark, or navigate to `https://concert.ibmdte.local:12443`.
3. Accept the certificate warning if prompted (**Advanced** then **Accept the Risk and Continue**).
4. Log in with the Concert credentials from your `credentials.txt` file:
   - **Username**: `ibmconcert`
   - **Password**: `Passw0rd`

### 3.4.2: Verify Concert Access

After logging in, you should see:
- The Concert dashboard with its navigation menu
- No error messages

:::note
The **Concert Secure Coder** card lives under the **Protect** tab in the top navigation. You will open it in Section 4 to download the extension and generate your API key — no action is needed on it yet.
:::

## 3.5: Preparation Checklist

Before proceeding to the next section, verify that you have completed all preparation steps:

- [ ] Connected to the Bastion Host
- [ ] Opened Firefox and reached the IBM Concert UI at `https://concert.ibmdte.local:12443`
- [ ] Accepted the certificate warning and signed in with `ibmconcert / Passw0rd`
- [ ] Created and saved `credentials.txt` with the Concert URL and login
- [ ] Confirmed the credentials file is open and ready for the API key you will add in Section 4

:::success

## Troubleshooting

:::info
This section provides basic troubleshooting steps in case you encounter issues while preparing your environment. These steps are optional and only needed if you run into problems.
:::

### Cannot reach the Concert UI

**Problem**: Firefox shows a connection error or timeout when opening `https://concert.ibmdte.local:12443`.

**Solutions**:
- Verify you are using Firefox **on the Bastion desktop**, not a browser on your own laptop.
- Confirm the URL uses `https://` and port `12443`.
- Accept the certificate warning (**Advanced** then **Accept the Risk and Continue**).
- Reload the page.

### Cannot log in to Concert

**Problem**: The Concert login is rejected.

**Solutions**:
- Confirm you are using `ibmconcert / Passw0rd` exactly, including the zero in `Passw0rd`.
- Reload the login page and try again.

### Credentials file lost

**Problem**: You accidentally closed the credentials file.

**Solutions**:
- Reopen **Text Editor**, recreate `credentials.txt` from the template in Section 3.3, and re-enter the values.
