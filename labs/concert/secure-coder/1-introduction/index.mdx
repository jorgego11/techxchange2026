# Introduction

IBM Concert Secure Coder brings security vulnerability detection and remediation directly into the developer's integrated development environment (IDE). Rather than waiting for a vulnerability to surface in a downstream pipeline scan, a security review, or a production incident, the developer sees the finding in the editor where the code was written and remediates it before the change is ever committed.

By integrating with the development workflow, Concert Secure Coder helps you identify and remediate vulnerabilities early, reduce manual effort, and improve overall code quality — all without leaving Visual Studio Code.

### Framing the SAST challenge

Static application security testing has traditionally sat at the wrong end of the development cycle. A vulnerability written on Monday surfaces in a pipeline scan on Thursday, gets triaged into a ticket the following week, and is fixed by a developer who has long since moved on to other work. Every step in that chain adds cost, context-switching, and risk.

### How IBM Concert Secure Coder adds intelligence

Concert Secure Coder combines several scanning engines behind a single IDE panel. Semgrep and Detect Secrets analyze the active file for insecure patterns and exposed credentials, while Mend SAST and Mend OSS analyze the whole repository — classifying source-code weaknesses against the CWE catalog and surfacing known vulnerabilities across the open source dependency tree. For supported findings, **Fix with AI** generates a proposed remediation, annotates it with a confidence score, and inserts it into your working copy for review.

### Shift-left is a location, not a slogan

The cheapest moment to fix a vulnerability is the moment it is written. Concert Secure Coder puts the finding in the editor, next to the line that caused it, with the file and line number already resolved — so detection, review, remediation, and verification all happen before a single commit.

### Lab Content

Welcome to the IBM Concert Secure Coder Lab. You will go through several key exercises that build the skills needed to detect and remediate security vulnerabilities directly in your IDE using IBM Concert.

In this Lab, you will explore the following topics:
- Install and authenticate the Concert Secure Coder extension in Visual Studio Code
- Run a Code Scan on a vulnerable file and review findings from Semgrep and Detect Secrets
- Apply an AI-generated remediation, review it, correct a side effect, and rescan to verify
- Remediate an exposed secret manually and confirm a clean scan
- Run repository-wide Mend SAST and Mend OSS scans and review CWE-classified findings

The lab should be executed in the numbered order that you see on the left side of the screen, in the navigation pane, as sections likely depend on work completed in prior sections.
